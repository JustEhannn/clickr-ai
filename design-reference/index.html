Clickr design reference

Clickr is a Mac app: a small floating AI "pill" you open with a keyboard shortcut. You ask a question, it can look at your screen to answer, and on the top plan it can click and type for you ("Agent Mode"). Everything below is the real interface running with fake data, so you can see exactly how it looks, hover over buttons, and type into it.

Everything on this page is a live copy of the app's real screens (not mockups or screenshots). Try typing in the windows, hover buttons, open Settings, switch the billing toggle. Nothing is saved or sent anywhere. The checkered / gradient areas are just a stand-in desktop; in the real app these windows float over whatever app you're using, and the glassy dark panels let that show through.

Type, shape, motion

FontInter, falling back to the Mac system font (SF Pro). Code uses SF Mono / Menlo.
CornersLarge and soft: panels about 24 px, buttons and chips 10-12 px, the pill fully rounded.
LookDark frosted-glass panels over the desktop, thin white borders at 6-10%, subtle shadows, blue only for the things you can act on.
MotionShort, smooth fades and slides (150-300 ms). Prices roll between monthly and annual. The AI's text streams in as it is written.
WebsiteThe site (clickrai.com) uses the same colors; this page covers only the Mac app.

The app, screen by screen

Each window below is exactly the size it has on a Mac.

1. The pill (idle)main window

Opens with a keyboard shortcut (⌘ ⇧ Space). Type a question and press Return. "Assist" (⌘ Return) looks at your screen first.

2. A screen-aware answer

Clickr looked at the screen and streams its reply.

3. First-run guide

A short tour shown once after sign-in.

4. Permission needed

Before it can see the screen, macOS asks the person to switch Clickr on in System Settings.

5. Sign in

360 × 410. Sign-in opens in the browser; this window waits.

6. Settings

340 × 640, scrolls. Includes Custom AI models, Memory, Agent Mode options, Shortcuts, Software update, Support.

7. Report a bug

380 × 470.

Plans and upgrade prompts

Three plans: Free, Pro ($9.99/mo, $7.99 billed yearly), Pro+ ($19.99/mo, $16.99 billed yearly). Locked features show an upgrade window like this one.

8. Pricing window

Monthly / Annual switch, "Save up to 20%".

9. Free plan limit reached

Automatic reply with an Upgrade button.

Agent Mode (top plan only)

While Agent Mode works, the chat hides itself. A small status pill and Clickr's own blue cursor remain so you can watch every move.
